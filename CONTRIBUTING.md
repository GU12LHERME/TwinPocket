# Contribuindo com o Twinsanity Pocket

Relate problemas e sugestões na [aba Issues](https://github.com/GU12LHERME/TwinsanityPocket/issues).

## Desenvolvimento

1. Consulte as [instruções de compilação](android/game/README.md).
2. Crie uma branch a partir de `android-game-arm64`.
3. Execute os testes relevantes e descreva os resultados no pull request.
4. Preserve os créditos e as licenças das dependências.

Não envie imagens do jogo, saves, credenciais ou dados pessoais. Para problemas de desempenho, use os relatórios da aba Ferramentas, revisando-os antes de compartilhar.
