# Troubleshooting / Solução de problemas

Download the latest APK from [Releases](https://github.com/GU12LHERME/TwinsanityPocket/releases/latest). Check Android and ARM64 compatibility in the README. Back up your data before reinstalling. For bugs, report the app version, Android version, device, steps and sanitized logs in Issues.

## Português

Baixe o APK mais recente pelo link acima. Confira os requisitos de Android e ARM64 no README. Faça backup antes de reinstalar. Para erros, informe versão do aplicativo, Android, dispositivo, passos e logs sem dados pessoais nas Issues.
