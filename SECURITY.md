# Security / Segurança

Report vulnerabilities privately through [Security Advisories](https://github.com/GU12LHERME/TwinsanityPocket/security/advisories/new), if enabled. Otherwise request a private contact channel without disclosing vulnerability details. Include affected version, reproduction steps and impact. Do not publish secrets or personal data.

## Português

Reporte vulnerabilidades de forma privada pelo link acima, se disponível. Caso contrário, solicite um canal privado sem divulgar detalhes da falha. Informe versão afetada, passos de reprodução e impacto. Não publique credenciais nem dados pessoais.
